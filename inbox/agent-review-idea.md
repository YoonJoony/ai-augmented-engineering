# 에이전트 리뷰를 학습으로 연결할 수 있을까

> 빠른 메모 예시입니다. 아래 질문은 아직 실험하거나 결론 내리지 않았습니다.

AI에게 코드 리뷰를 맡기기 전에 내가 먼저 위험한 부분과 확인 방법을 적어보면 어떨까?

- 내가 발견한 문제와 에이전트가 지적한 문제는 어떻게 다를까?
- 에이전트의 지적 중 실제 문제가 아닌 것은 무엇일까?
- 수정 후 같은 종류의 문제를 혼자 설명하고 찾을 수 있을까?

다음 정리에서는 작은 변경 하나를 골라, 내 리뷰와 에이전트 리뷰를 비교하는 실험 계획으로 옮깁니다.
