# 오픈소스 학습·개발 스킬 비교 이해 확인 질문지

## 원래 질문과 답변의 핵심

- 사용자 질문: AI에게 끌려가는 개발, AI 슬롭, 근거 없는 구현, 설계 이해 없는 위임을 지적하고 학습을 돕는 오픈소스 스킬이 있는가?
- 답변의 핵심: 소크라테스식 튜터링, 설계 전 질문, 검증 증거, 과잉 구현 억제, 직접 코딩 참여를 다루는 사례가 있습니다. 확인한 후보는 목적이 달라 조합과 수정이 필요하며, 설치나 자동 로딩 자체가 이해와 행동 준수를 보장하지는 않습니다.
- 출처와 비교: [오픈소스 스킬 조사 기록](../references/open-source-skills-for-independent-engineering.md)

## 선행 확인 기록

해당 없음. 후보를 탐색하는 질문이며 구체적인 전제 오류는 확인되지 않았습니다. 이해도 진단이나 특정 설계 채택에 대한 통과 판단은 하지 않았습니다.

## 이해 확인 질문

1. AI가 작성한 설계안에 내가 승인 버튼을 누른 것만으로, 설계를 이해했다고 판단할 수 있을까요? 이해를 확인하려면 무엇을 추가로 해봐야 할까요?
2. 스킬을 설치한 뒤에도 AI가 근거 없이 구현을 시작했다면, 스킬 파일이 있다는 사실 외에 무엇을 확인하겠어요?

## 사용자 응답

미응답. 실제 응답을 받은 뒤 기록합니다.

## 응답 평가

평가 대기. 이해한 부분, 보완할 부분과 판단 근거를 실제 응답에 맞춰 적습니다.

## 문제집으로 남길 핵심

선별 대기. 사용자 응답 후 중요한 항목만 선정합니다.
