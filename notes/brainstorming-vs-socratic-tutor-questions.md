# brainstorming과 socratic-tutor 차이 이해 확인 질문지

## 원래 질문과 답변의 핵심

- 사용자 질문: obra/superpowers의 brainstorming과 Jane Street의 socratic-tutor는 무엇이 다른가? (사용자 가설: brainstorming은 구현 전 요구사항·설계 확인과 검증 증거 요구, socratic-tutor는 질문에 대한 확인 지침)
- 본답변의 핵심 [AI 답변]: "검증 증거 요구"는 brainstorming이 아니라 verification-before-completion 스킬의 내용입니다. brainstorming은 구현 전에 무엇을 왜 만들지 합의하는 관문입니다. socratic-tutor는 사용자가 명시적으로 학습을 요청했을 때 진행하는 튜터링 세션 운영 방법이며, 구현 전 관문이 아닙니다.
- 관련 메모·자료·글: [socratic-tutor 한국어 번역](../references/socratic-tutor-ko.md), [오픈소스 스킬 비교](../references/open-source-skills-for-independent-engineering.md)

## 선행 확인 기록

해당 없음.

## 이해 확인 질문

1. AI가 "socratic-tutor는 구현 전 관문이 아니다"라고 했습니다. 이 말을 직접 확인하려면 SKILL.md의 어느 부분을 보겠습니까? 거기서 무엇이 보이면 맞는 말이라고 판단하겠습니까?

## 사용자 응답

### 1차 응답 (2026-11-25)

- 되물음: "구현 전"이라는 말이 구현 전에만 쓰이는 스킬이라는 뜻인지 물었습니다.
- 사용자 이해: socratic-tutor는 구현 전이 아니라 모든 학습 세션에서, 사용자의 질문 의도가 애매하거나 잘 모르면서 요청하는 추상적인 맥락을 파악하고 사용자에게 되묻는 스킬이라고 봅니다.
- 근거 위치: "안전장치" 부분을 볼 때 맞는 말이라고 판단했습니다.

## 응답 평가

### 1차 평가 (2026-11-25): 부분 충족, 재질문 중

- 타당한 부분: 확인할 위치로 "안전장치"를 고른 것은 원문과 맞습니다. 결론(구현 전 관문이 아니다)도 원문과 일치합니다.
- 용어 확인: "구현 전 관문"이라는 AI의 표현이 모호해 사용자가 되물었습니다. AI가 표현의 뜻을 설명했습니다.
- 보완할 부분: 안전장치가 하는 일을 "요청의 추상적 맥락 파악"으로 넓게 설명했습니다. 원문의 안전장치가 실제로 사용자에게 고르게 하는 선택지와 이 설명이 같은지 아직 확인되지 않았습니다.
- 평가 근거: [번역본의 "안전장치" 절](../references/socratic-tutor-ko.md#안전장치-시작-전에-의도-확인)

## 문제집으로 남길 핵심

선별 대기. 재질문 응답을 받은 뒤 결정합니다.
