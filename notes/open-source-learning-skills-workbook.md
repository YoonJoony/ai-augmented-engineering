# 설계 이해와 스킬 동작을 검증하는 핵심 문제집

## 원래 질문지와 선별 이유

- 원래 질문지: [오픈소스 학습·개발 스킬 비교](open-source-learning-skills-questions.md)
- 실제 응답에서 설계 검증과 대안 비교의 필요성은 드러났지만, 본인의 이해를 보여줄 수행 기준은 아직 구체적이지 않았습니다.
- 스킬의 설치와 사용 방법을 점검하겠다는 응답에는 실제 동작을 판단할 관찰이나 증거가 구체적으로 제시되지 않았습니다.
- 이 두 항목은 이후 설계와 에이전트 활용에도 반복해서 필요한 판단이므로 남깁니다. 해설은 재풀이 전에 공개하지 않습니다.

## 문제 1: 설계안 없이 판단해보기

개인 블로그용 글과 메모를 관리하는 서비스를 만들려고 합니다. 작성자는 한 명이고 초기 예상 독자는 하루 100명이며, 서버 운영에 쓸 수 있는 시간은 주당 1시간입니다. AI는 여러 서비스와 메시지 큐를 사용하는 설계를 제안했고, 당신은 설명을 읽고 이해한 것 같아 승인하려 합니다.

AI의 설계안을 가린 상태에서, 자신이 무엇을 설명하거나 수행할 수 있어야 이해했다고 볼지 정해보세요. 그 확인 과정에서 생긴 의문을 AI에게 어떤 질문으로 돌려줄지도 적어보세요. 특정 아키텍처의 이름을 정답으로 고르는 문제는 아닙니다.

## 문제 2: 설치 후에도 바로 구현하는 에이전트

튜터 SKILL.md 파일은 프로젝트 안에 있습니다. 당신이 "내 서비스에 맞는 아키텍처를 만들어줘"라고 요청했더니, AI는 당신에게 질문하지 않고 곧바로 코드를 작성했습니다. 아직 원인은 모릅니다.

가능한 원인을 두 가지 이상 가설로 적고, 각 가설이 맞는지 무엇을 관찰하거나 시험해서 판단할지 써보세요. "내가 잘못 썼는지 확인한다"를 실제 행동과 관찰 가능한 결과로 구체화하는 것이 목표입니다.
