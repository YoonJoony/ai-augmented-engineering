# 학습 대화 방식 이해 확인 질문지

## 원래 질문과 답변의 핵심

- 사용자 요청: 답변마다 질문지를 만들고, 실제 응답에서 중요한 항목만 골라 문제집으로 남깁니다. 잘못된 전제나 이해의 공백이 드러나면 확인 질문에 타당하게 답할 때까지 본답변을 보류합니다.
- 답변의 핵심: 선행 확인, 본답변과 질문지, 실제 응답 평가, 핵심 문제집과 재풀이를 연결합니다. 사실 문제는 정확성으로, 설계 문제는 제약과 근거의 타당성으로 평가합니다.
- 관련 문서: [학습 대화 운영 원칙](learning-dialogue-protocol.md)

## 선행 확인 기록

해당 없음. 이번 요청은 학습 방식을 정하는 요청으로, 본답변을 보류해야 할 구체적인 전제 오류는 확인되지 않았습니다.

## 이해 확인 질문

1. AI가 추천했다는 이유로 새로운 아키텍처를 도입하려 할 때, 채택 전에 직접 설명하거나 확인해야 할 것은 무엇인가요?
2. 정답이 여러 개인 설계 문제에서, 자신의 답이 타당하다는 것을 어떤 근거로 보여주겠어요?

## 사용자 응답

미응답. 실제 응답을 받은 뒤 기록합니다.

## 응답 평가

평가 대기. 사용자 응답에서 이해한 부분, 보완할 부분과 평가 근거를 기록합니다.

## 문제집으로 남길 핵심

선별 대기. 실제 응답 후 중요한 항목만 골라 문제집으로 연결합니다.
